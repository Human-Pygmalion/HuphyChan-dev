# 162. 다음 계획 — 험지 정책을 본 정책으로 (2026-10-11)

> 약어를 쓰지 않는다. 근거: [[2026-10-11_flat_vs_rough_policy_compare]], [[2026-10-10_ab_rough_stagnation_compare]], [[2026-10-09_reward_termination_review]].

## 지금 어디에 있나

- 험지 학습(v11a 배우에서 이어서 3,000 회)이 **산길 182 m 를 양방향 완주**하고, 같은 험지에서 넘어짐을 절반 이하로 줄였다. 서기도 더 차분해졌다.
- 대신 평지에서 **제자리 회전이 51 % → 1 %**, 걷기 속도가 명령보다 19 % 빠르고, 걸음의 좌우 대칭이 나빠졌다.
- 학습 기반 시설 결함 세 가지를 고쳤다(모두 플래그): 몸통 낮음을 발밑 땅에서 재기, 물리 발산 환경 끝내기(NaN·속도 폭주), 보상 항목 상한.
- 남은 의문: **학습 시뮬레이터의 높이 지도 접촉 결함**(평평한 높이 지도에서도 걷다 주저앉음 — 험지의 40 % 가 높이 지도 타일), 발목 연결봉 폭주의 근본 원인(같은 뿌리일 가능성), 회전 상실의 원인.

프로젝트의 목표는 **실제 하드웨어 설계 하중**이다. 최종 정책은 평지·험지 모두에서 명령을 잘 따라야 하중 측정이 의미 있다.
그래서 순서는 "원인 가르기 → 측정 도구 바로잡기 → 회전 회복 설계 → 본 학습 → 하중 측정" 이다.

## 순서 (각 단계: 할 일 · 완료 기준 · 걸리는 시간 · 사람 결정 필요 여부)

| # | 할 일 | 완료 기준 | 시간 | 결정 |
|---|---|---|---|---|
| 1 | **회전 상실 원인 가르기** — A 팔(정체 종료 없음)의 평지 측정(`run_v10_set.sh rougha`) | A 도 회전 < 10 % 이면 "험지 학습 공통", A 가 v11a 수준이면 "정체 종료 탓" | 약 1 시간 (진행 중) | 아니오 |
| 2 | ~~험지 평가 이상 고치기~~ → **원인 확인: 학습 시뮬레이터(MuJoCo-Warp)의 높이 지도 접촉이 걷는 발에서 잘못 작동** — 완전히 평평한 높이 지도에서 77~100 % 주저앉고 같은 평평함의 상자 바닥은 0 %. 다음: 발 충돌 모양(상자 3 개)과 높이 지도 간격을 바꿔 보거나, 높이 지도 타일을 메시 지형으로 바꾸는 시험 → 본 학습 전에 결정 |
| 3 | **정식 실험 노트** — 험지 A/B 각 팔의 노트(보상·이득·액추에이터·관절 범위·플래그 표 자동 삽입, 학습 곡선) + 대장·계보도 | 노트 2 개 + 대장 행·계보도 노드 | 1 시간 (위임) | 아니오 |
| 4 | **회전 회복 설계** — 1 의 결과로 원인 확정 → 근거 노트(문헌 + 우리 기록) → 후보: 제자리 회전 명령 비율 명시, 평지 비율 상향, 회전 추적 가중, 평지 짧은 미세조정 중 택일 | 근거 노트 + 짧은 단일 변인 시험(1,000 회)에서 회전 중앙값 ≥ 50 % 회복 | 반나절 | 아니오 (결과 보고) |
| 5 | **발목 연결봉 폭주 근본 원인** — 수동 연결봉 관절에 작은 감쇠·관성(armature)을 넣은 모형 사본으로 폭주율 측정(`rough_blowup_probe.py`, 학습 없음) | 폭주 0 / 백만 걸음 이면서 걷기 지표 불변 | 2 시간 | **예** — 로봇 모형 값 변경이므로 채택 전 승인 |
| 6 | **본 학습 (험지 2단계)** — 험지 B 에서 이어서: 무작위화(밀기·마찰·질량) 경사 + 엔트로피 감쇠 + 정체 종료 + 보호 장치 + 4 의 회전 대책(+ 5 를 승인받으면 모형 수정). 3090, 약 12,000 회 | 아래 사전 기준 | 약 20 시간 | **예** — 발사 전 설계 확인 |
| 7 | **최종 하중 측정** — 본 정책으로 평지·험지 전 명령상자 하중(`measure_full` 깨끗·밀기), 설계 하중 문서 갱신 | 설계 하중 표(열 = 실효값 × 1.15, 순간 = 99 백분위 × 1.25) | 1 일 | 아니오 |
| 8 | **영상·그림 갱신** — 본 정책으로 산길 완주·나란히 영상, 기사 그림 | 실시간 영상 2 편 | 2 시간 | 아니오 |

| 항목 | 기준 |

| 같은 험지 (고친 평가) | 단계 6 넘어짐 ≤ 10 %, 추종 오차 ≤ 0.25 m/s |

| 평지 서기 | 발 뗀 ≤ 2 %, 27 초 흘러감 ≤ 0.3 m |
| 학습 건강 | 보상 폭주 0, NaN 0, 물리 폭주 종료 ≤ 0.1 / 회 |
