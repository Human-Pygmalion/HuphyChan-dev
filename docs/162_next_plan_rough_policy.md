# 162. 다음 계획 — 험지 정책을 본 정책으로 (2026-10-11)

> 약어를 쓰지 않는다. 근거: [[2026-10-11_flat_vs_rough_policy_compare]], [[2026-10-10_ab_rough_stagnation_compare]], [[2026-10-09_reward_termination_review]].

## 지금 어디에 있나

- 험지 학습(v11a 배우에서 이어서 3,000 회)이 **산길 182 m 를 양방향 완주**하고, 같은 험지에서 넘어짐을 절반 이하로 줄였다. 서기도 더 차분해졌다.
- 대신 평지에서 **제자리 회전이 51 % → 1 %**, 걷기 속도가 명령보다 19 % 빠르고, 걸음의 좌우 대칭이 나빠졌다.
- 학습 기반 시설 결함 세 가지를 고쳤다(모두 플래그): 몸통 낮음을 발밑 땅에서 재기, 물리 발산 환경 끝내기(NaN·속도 폭주), 보상 항목 상한.
- 남은 의문: **학습 시뮬레이터의 높이 지도 접촉 결함**(평평한 높이 지도에서도 걷다 주저앉음 — 험지의 40 % 가 높이 지도 타일), 발목 연결봉 폭주의 근본 원인(같은 뿌리일 가능성), 회전 상실의 원인.

프로젝트의 목표는 **실제 하드웨어 설계 하중**이다. 최종 정책은 평지·험지 모두에서 명령을 잘 따라야 하중 측정이 의미 있다.
그래서 순서는 "원인 가르기 → 측정 도구 바로잡기 → 회전 회복 설계 → 본 학습 → 하중 측정" 이다.
