## 1. 무작위화 (가장 큰 구멍)

현재 있는 것: 리셋 자세·관절 흔들기, 밀기, 발 마찰, 엔코더 치우침(±0.86°), 질량·관성(`PYG_MASS_DR_JSON`, `PYG_INERTIAL_DR`), 관측 잡음.
**없는 것: 지연 전부, Kp·Kd, 모터 세기, 응답 유실, IMU 부착각.**

| # | 넣을 것 | 범위 | 근거 | 넣는 곳 |
|---|---|---|---|---|
| 1-1 | **관절 관측 지연** | 0~1 정책 주기(0~20 ms) | 실측: 실물은 한 주기 늦은 관절값을 본다 | 관절 이력 관측 `delay_*_lag` (지금 0) |

## 2. 밀기 — 너무 세다

| | 지금 | 권장 | 근거 |
|---|---|---|---|
| 간격 | **1~3 초마다** | **8~15 초** | 걷기 정책 표준(legged_gym·Isaac Lab 사례 10~15 초). 1~3 초면 한 걸음마다 밀린다 |
| 수평 속도 | ±0.7 m/s | ±0.5 m/s | |
| 수직 속도 | ±0.4 m/s | 0 | 실제 외란에 거의 없음 |
| 회전 속도 | 롤·피치 ±0.52, 요 ±0.78 rad/s | 0 (또는 ±0.2) | 6축 동시 강제 속도는 과함 |

세기를 낮추는 대신 램프는 유지. 강건성은 "밀기 내성 측정"(`stand_robustness`)으로 따로 확인한다 — v7b 는 1.5 m/s 밀기도 0 넘어짐이었다.
밀기가 과하면 자세 보상을 포기하고 넓게 버티는 쪽으로 간다(v9_caps 다리 벌림, 2단계 외력 램프 뒤 자세 보상 붕괴 — `docs/experiments/2026-10-14_standonly_pose_audit.md`).

## 4. 보상 — 중복 정리와 규제 보강

**효과 없는 항 (정리)**: `soft_landing` 가중치 −1e-5 (사실상 0), `torque_limit` 0.

**겹치는 묶음 (같은 것을 여러 번 상벌 → 가중치 의미가 흐려짐)**

| 묶음 | 항 | 정리안 |
|---|---|---|
| 속도 추종 | `track_linear_velocity` 2.0 + `track_lin_vel_progress` 1.0 | 하나로 (진행 항의 필요성 재확인) |
| 발 들기 | `air_time` 1.0 + `foot_clearance` −2.0 + `foot_swing_height` −0.25 | 둘 이하로 |
| 착지 | `soft_landing` + `foot_impact_velocity` −0.5 + `contact_force_cap` −0.01 | 하나 또는 둘 |
| 몸통 회전 | `upright` 1.0 + `body_ang_vel` −0.05 + `angular_momentum` −0.02 | 역할 분리 확인 |

**빠진 규제 (표준 걷기 설정 대비)**

| 넣을 것 | 이유 |
|---|---|
| 관절 가속도 벌점 | 떨림·충격. 지금은 행동 1차 변화(`action_rate_l2`)만 있음 |
| 행동 2차 변화 벌점 | `mean_action_acc` 는 기록만 하고 벌하지 않음 |
| 몸통 상하 속도 벌점 | 출렁임 |
| **두 발 간격 / 발목 좌우 내부 힘** | 서기 중 두 크랭크가 서로 반대로 미는 힘 ±11 N·m, v9_caps 다리 벌림 |
| **자세 보상 허용폭 확대** | `std_standing` 전 관절 0.05 rad(2.86°) — 몇 도만 벗어나도 보상·기울기가 0 이 되어 돌아오지 못함 |

## 5. 커리큘럼·게이트

- 3→4 승급이 v6b 부터 v11a/b 까지 **매번** 5,400 에 강제 — 게이트 오차가 정책 개선과 반대로 움직인다. 후보: 잡음 없는 고정 명령 평가 / 단계 안 기울기 0 / 명령 크기로 나눈 상대 오차 (`docs/experiments/2026-09-25_ab_v10_stand_l1_compare.md` §4-7).
- 서 있는 비율 0.1 유지(0.3 보다 회전 51 % 대 9.5 %, 서기 같음 — v11 비교).
- 거친 지형 학습은 게이트를 끈 상태였고 설정 기록이 1단계 범위만 남음(감사 F5).

## 6. 명령 추종

- 제자리 회전 ±0.25 rad/s 죽은 구간(모든 팔), 거친 지형 정책 중앙값 45 %·반대 1~2/8.
- 0.3 m/s 명령에서 걷지 않음 — `stand_still_penalty` 경계 0.3 추정(미검증).
- 1.2 m/s 명령에 1.32 실제(+10 %), 좌우 비대칭 +18 % — 원인 미상.
- 회전은 씨앗에 크게 흔들림(v10a 91 % 대 v11a 51 %) → 판정은 씨앗 반복으로만.

## 7. 실행 순서 제안

1. 0번 확인(사람) — 특히 0-1 모터 종류, 0-3 하드스톱.
2. **단일 변인 A/B 묶음 (3090, 같은 씨앗)**, 기준선 = rough_box_main_v11a 설정:
   - A: 무작위화 1-1·1-2·1-3·1-5 (지연·게인·유실)
   - B: 밀기 완화(2절)
   - C: 크랭크 게인 55/2.5
   판정: 실기 조건 시뮬(`tools/sim2real/real_condition_sim.py`) 전 조건 + 서기·걷기·회전 측정 세트 + 밀기 내성.
3. 위 결과로 기준선 갱신 후, 보상 정리(4절, 근거 조사 먼저)와 엉덩이·무릎 게인.
4. 게이트 수정은 별도 A/B.
