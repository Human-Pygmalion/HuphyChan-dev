## 3-1. 05:18 사고: 세 번째 학습이 메모리 부족으로 죽음

- 05:18 에 큐가 `v5_hr2` 를 띄웠고 05:20 에 `Warp CUDA error 2: out of memory` 로 죽었습니다. `v5clean`, M19 이어 학습, `v5_hr8`(이미 정상 종료)은 영향이 없었습니다.
- 원인: M19 학습의 시작 스크립트가 `RUN_NAME` 을 실제 런 이름(`m19_ft_from49999_2500`)으로 덮어써서, 큐가 `sole_ft_` 로 시작하는 이름만 세는 탓에 M19 를 빈 칸으로 봤습니다. 발사 때 GPU 여유가 9,105 MiB 로 기준(9,000)에 겨우 걸쳤습니다.
