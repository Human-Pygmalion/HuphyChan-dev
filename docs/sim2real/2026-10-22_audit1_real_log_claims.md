## 0. 먼저 읽을 결과

- 14개 주장 중 11개는 확인됐다. 3개는 고쳐야 한다 (C3 의 "12개 관절 모두", C10 의 "Kd×1.5 에서 R_hip_pitch 만", C11 의 진폭 숫자). C14 는 숫자는 맞고 "데드밴드 아님" 의 추론이 절반만 선다.
- 5 Hz 떨림은 **별칭 (aliasing) 이 아니다.** 기록 시각이 불균일해서 별칭이 억제된다. 어떤 참 주파수의 사인파도 관측 봉우리로 새는 비율이 2.5 % 이하다. 관측 전력은 떨림 구간에서 15~67 % 다.
- 5 Hz 떨림은 **지속 신호가 아니라 구간 (에피소드) 신호다.** `vib-check` 에서 39 s 에 시작해 약 115 s 까지, 130 s 부터 약 192 s 까지 이어진다. 0~38 s 에는 없다. 시작은 1 s 안에 일어난다. 시작 직전 몸통이 앞으로 7.7° 기울고 자이로가 124 deg/s 까지 오른다.
- 5 Hz 에너지를 나르는 입력은 **관절각이 아니라 각속도와 직전 행동이다.** 관절각 입력을 전부 평균값으로 고정해도 5 Hz 전력은 줄지 않는다 (×1.06).
- 각속도 영점 편향 (−1e-5 rad/s) 은 편향 측정이 아니다. 정지 구간의 각속도가 정확히 0 이어서 나온 값이다.

## 2. 5 Hz 떨림의 별칭 검사 (C3, C12)

### 2-a. 별칭이 아니라는 근거

기록 시각 간격은 평균 54 ms (표본 주파수 18.4 Hz) 이고 나이퀴스트 주파수는 9.2 Hz 다. 간격이 불균일하므로 (p5 42 ms, p95 71 ms) 균일 격자의 별칭이 억제된다. 네 가지로 확인했다.

1. **표본 창 검사.** 기록된 `t` 에서 순수 사인을 표본 추출해 Lomb–Scargle 을 돌렸다. 5.09 Hz 사인은 5.09 Hz 에 전력 1.0 으로 나온다. 13.32 Hz (= 18.4 − 5.09) 사인은 13.32 Hz 에 1.0 이고 5.09 Hz 로 새는 양이 0.011 이하다. 균일 시각이었다면 13.32 Hz 는 5.09 Hz 로 전력 1.00 으로 접힌다.
2. **누설 상한.** 1~100 Hz 의 모든 참 주파수 (관측 ±1 Hz 제외) 에 대해 관측 봉우리로 새는 전력은 `vib-check` 에서 최대 0.025 (참 주파수 25.4 Hz), 1020 에서 0.011 (94.2 Hz) 이다. 관측 전력은 떨림 구간 10 s 창에서 0.15~0.67 이다. 상태가 호출 시각보다 최대 12 ms 오래됐다고 가정해도 (시각 오차 U[0,12] ms) 누설은 0.016 이하다.
3. **공통 후보.** 표본 주파수 18.4 Hz 와 30.3 Hz 에서 같은 별칭 쌍을 만드는 참 주파수는 약 24 Hz 뿐이다 (5.1 ↔ 23.5, 5.7 ↔ 24.6). 위 누설 검사가 이 후보를 배제한다. LS 0.3~60 Hz 에서 24 Hz 부근 봉우리는 없다 (0.005 이하).
4. **리샘플링 비교.** 균일 격자로 다시 표본 추출한 Welch 도 같은 봉우리를 준다. 간격 20 ms 5.08 Hz, 54 ms 5.04 Hz, 100 ms 4.96 Hz. 멈춘 행은 떨림 구간에 0 개다. 그래서 멈춤이 만든 봉우리도 아니다.

### 2-b. 눈으로 본 시계열과 정책 단계 수

- 2 s 창 (150~152 s) 에 행동 봉우리 10개가 있다. 봉우리 사이는 정책 3단계와 4단계가 번갈아 나온다 (3,4,3,4,3,4,3,4,3). 시간 간격은 143~259 ms 다. 60~62 s 창에는 9개다.
- 떨림 구간 전체의 평균 주기는 3.62~3.83 정책 단계 (199~205 ms) 다. 정수 단계가 아니다.
- 1020 은 33 ms 간격에서 주기 5.1 단계 (170~180 ms) 다. 간격이 1.6배로 늘 때 주기는 1.12배로 는다 (176 → 196 ms). 시간 주파수가 거의 고정되고 단계 수가 바뀐다.
- **C12 의 논리 평가.** 정책 단계에 묶인 지연 한계 순환이라면 주기는 단계 간격에 비례한다. 순수 지연 모형 (한계 순환 주기 = 4 × 지연, 지연 = 1~1.5 단계) 으로 어림하면 주기가 간격의 4~6배씩 늘어야 한다 (+90~130 ms). 이 값은 모형 추정이다. 관측은 +21 ms 다. 그러므로 "주파수는 간격이 아니라 몸 쪽 응답이 정한다" 는 논리는 선다. 보강 근거: tgt→pos 지연이 두 실행에서 같다 (1020 hip_pitch 61 ms, 1021 58~60 ms). 한계: (i) 점 두 개다. 날짜, 손으로 잡은 상태, 루프 주기 (16.5 대 13.6 ms) 가 함께 다르다. (ii) 한 실행 안에서 주파수가 4.8~5.24 Hz 로 흔들린다. 0.6 Hz 차이는 그 폭의 2~3배 정도다. (iii) 단계 간격이 늘면 `q − q_prev` 가 2.5~3배 커서 되먹임 이득도 함께 오른다. 에너지 쪽 가설은 이 자료로 갈리지 않는다.

## 3. 새로 발견한 것

**N1. 5 Hz 에너지는 각속도와 직전 행동이 나른다 (관절각이 아니다).** `vib-check` 50~110 s, 4.4~5.8 Hz 행동 전력. 입력 묶음을 평균값으로 고정한 열린 고리 반사실이다.

| 조작 | 기준 대비 전력 |
|---|---|
| 각속도만 변함 | 0.81 |
| 직전 행동만 변함 | 0.31 |
| 관절각 (q, q_prev) 만 변함 | 0.19 |
| 중력만 변함 | 0.02 |
| 각속도를 고정 | 0.69 |
| 직전 행동을 고정 | 0.69 |
| 관절각 전부 고정 | 1.06 |

replay 문서 §4-3 은 hip_roll 관절각 이득이 가장 커서 떨림을 증폭한다고 읽을 수 있다. 이득이 큰 입력이 실제 5 Hz 기여가 큰 입력은 아니다. 관절각은 5 Hz 에서 ±0.7° 만 움직인다. 각속도는 rms 35 deg/s (0.6 rad/s) 이고 블록 이득이 21 도/(rad/s) 다. 이 결과는 열린 고리다. 닫힌 고리의 인과는 보여 주지 못한다. 코히런스 0.98 도 인과가 아니다. `act` 는 `pos` 를 입력으로 받는 결정적 함수이므로 코히런스가 높은 것이 당연하다.

**N2. 떨림은 큰 교란 뒤에 시작한다.** `vib-check` 38.0~39.9 s 에 중력 x 가 0.027 에서 0.135 로 오른다 (앞 기울기 1.5° → 7.8°). 39.6 s 이후 자이로 크기가 32, 124, 98 deg/s 로 튄다. 1 s 안에 행동 표준편차가 0.005 에서 0.365 로 오른다. 그 뒤 약 75 s 동안 5 Hz 가 이어진다. 두 번째 구간 (130~192 s) 도 있다. 사이 115~130 s 는 약해진다. 정책은 정지 상태에서 조용하고 (행동 표준편차 0.001~0.026) 큰 교란이 들어오면 5 Hz 상태로 넘어가서 머문다. 양쪽 상태가 모두 안정하다는 뜻이다. 이는 선형 분석으로 설명되지 않는다.

**N3. 각속도 편향 추정이 무의미하다.** replay 문서 §0.3 의 편향 (−1e-5, +3e-5, +1e-5 rad/s) 은 정지 구간의 각속도가 정확히 0 이어서 나온 평균이다. 센서가 정지에서 0 을 출력하므로 (C6, C14) 실제 편향은 이 자료로 알 수 없다. "IMU 자체는 정상" 은 과하게 쓴 표현이다. 정책은 정지에서 각속도 입력 0 을 받는다. 학습 잡음은 ±0.2 rad/s 균등이었다.

**N4. vx0 방위 드리프트는 표본 잡음 안에 있다.** C7 표 참조. 큰 변화는 10 s 창 하나에 모인다 (1020 마지막 창 +5.2 deg/s, Kd×1.5 첫 창 −4.9 deg/s). Kd×1.5 는 5 s 이후 평균이 −0.01 deg/s 다.

**N5. 크랭크의 "추적 오차" 는 대부분 정책이 요구한 정적 오프셋이다.** `vib-check` 20~22 s 의 조용한 구간에서 크랭크 tgt−기본 = (−6.6, +8.8, +5.2, −7.0)° 이고 pos−기본 = (−1.1, +1.3, +0.3, −0.9)° 다. 오프셋은 떨림 구간 안팎에서 같다 (오차 −5.5/−4.0/−4.5 등). 정책이 발목 토크를 목표 오프셋으로 요구하고 실제 크랭크는 1~2° 만 움직인다. 시뮬레이터에서 같은 서기 자세의 tgt−q 와 비교해야 이것이 실기 고유의 오차인지 정해진다. 이 비교는 아직 없다.

**N6. 걸음의 거울 규약은 맞다.** 오른쪽과 왼쪽 hip_pitch 의 위상 −171° 는 물리적 반대 위상 (정상 걸음) 이다. hip_pitch 축은 좌우가 반대 부호 (`axis 0 1 0` 대 `0 -1 0`) 이고 hip_roll, hip_yaw 축은 같은 부호다. 한계값의 거울 대칭과 맞는다.

## 5. 검증하지 못한 것
