## 4. 사실

1. **작은 교란에서는 둘 다 끝까지 선다.** nominal, 관측 한 주기 지연, 안전 가드, 응답 유실 2%, 실기 시간차 묶음, 게인 0.8 배: 두 정책 모두 8/8 이 20 초 생존. 서 있을 때 행동 크기는 v7b 가 더 작다 (|행동| p99 1.2~1.9 대 rough 2.0~2.7).
2. **실기와 같은 중력 x 부호 반전 + 시간차 (게인 1.0)**: rough 는 8/8 이 2.0~4.7 초 (평균 2.8) 에 넘어졌고, v7b 는 8/8 이 20 초 생존 (|행동| p99 1.35, 무릎 표준편차 0.2 도). 중력 x 반전만 단독으로 줘도 (전체 실행): rough 2.2 초 0/8, v7b 20 초 8/8. 두 정책이 서 있을 때 관측된 중력 x 의 크기는 json 에 기록되지 않아, 부호 반전이 값을 실제로 얼마나 바꾸는지는 확인하지 못했다.
3. **중력 x 치우침 +0.1**: v7b 는 무릎 0.1~0.2 도로 정지에 가깝게 서고, rough 는 서지만 무릎이 2.2~2.8 도, 1.1~1.2 Hz 로 작게 흔들린다. 치우침 −0.1 에서는 rough 도 0.3 도로 조용하다. 자이로 앞뒤 축 반전 (`gyro_yz flip`) 과 위쪽 축 180 도 회전 (`yaw180`) 은 둘 다 0.2~0.7 초 안에 8/8 넘어짐 (v7b 와 rough 모두).
4. **게인 배율**: 0.8, 0.7 은 v7b 가 8/8 생존 (무릎 0.2 도). rough 는 0.8 에서 8/8, 0.7 에서 7/8 (한 번이 17.1 초에 넘어짐, 무릎 표준편차 평균 8.4 도). 0.5/0.5 는 둘 다 8/8 넘어짐 (v7b 1.2~1.4 초, rough 1.8~4.6 초). 0.1/0.1, 0.05/0.3, 0.05/0.5 (줄 없이) 는 둘 다 1 초 안팎에 8/8 넘어짐 (v7b 0.7~1.1 초, rough 0.5~0.6 초); 0.05/1.0 은 v7b 3.4 초 (1/8 끝까지), rough 0.7 초.
5. **실기 게인 0.05/0.3 + 크레인 줄 1 에서 0 으로 풀기**: 둘 다 8/8 넘어짐. v7b 는 10.5~11.7 초, rough 는 7.3~10.3 초. v7b 의 |행동| 3 초과 시점은 8.8~10.2 초 (줄 지지가 약해지는 때) 이고 한 번만 0.1 초, rough 는 8 번 중 6 번이 0.3~1.2 초 (시작부터). 줄이 0.5 또는 0.9 로 고정되면 둘 다 8/8 생존 (rough 는 0.9 에서 무릎 4.9 도, 자이로 11 도/초로 흔들림, v7b 는 0.4 도, 2 도/초).
6. **게인 1.0 + 크레인 줄 1 에서 0 으로 풀기**: 이번 14 조건 실행에서 v7b 7/8 (한 번이 6.6 초에 넘어짐, 나머지 20 초, 무릎 3.6 도 / 5.1 Hz / 자이로 48 도/초), rough 8/8 (무릎 10.0 도 / 0.43 Hz). 같은 조건을 다른 무작위값으로 다시 돌린 v7b 실행 (환경 296 개) 은 8/8 생존, 무릎 2.2 도 / 5.7 Hz. 즉 이 조건에서 v7b 의 무릎은 약 5 Hz 로 2~4 도 흔들리고, 넘어짐이 한 번 났다가 한 번은 안 났다 (시행 8 번으로는 확률 불확실).

## 5. 한계 (확인하지 못한 것)

- 시험은 서기 명령 0 하나. 걷기 명령, 밀기, 시작 기울기, 관측 잡음 아래에서의 v7b 는 이 시뮬레이터로 시험하지 않았다. v7b 는 학습 때 이것들을 겪었다.
- 시뮬레이터의 시작은 기본 자세. 실기는 시작 때 몸통이 3.5~7 도 기울어 있었다 (기울기 센서 치우침과 실제 자세 구분 안 됨). 그 상황의 가장 가까운 대용은 "중력 x 치우침 +0.1" 조건 뿐이다.
- 반복 8 번이라 생존 비율의 불확실성이 크다 (7/8 과 8/8 의 구분은 이 표본으로 안 된다).
- v7b 저장본은 model_8998 하나. 다른 저장본 (7900, 8000 등) 은 시험하지 않았다.
- 실기에서는 v7b 를 시험한 적이 없다.
