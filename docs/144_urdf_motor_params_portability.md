# 모델 파일만 다른 시뮬레이터로 옮기면 **다른 로봇**이 된다 — 고친 기록

2026-09-15 · 사용자 지시:

> *"최신 mjcf 에 있는 설정 중에 urdf 에도 쓸수있지만 override 하도록 설정된 값들이 있나?
> 그런게 있으면 urdf 에도 업데이트해줘. 실제로 나중에 로봇을 다른 플랫폼 시뮬쪽에 달면
> 문제가 될거같아."*

**맞는 지적이었습니다.** 실측해서 확인하고 고쳤습니다.

## §1 무엇이 어긋나 있었나

우리 학습 도구(mjlab)는 모델 파일을 읽은 **뒤에** 액추에이터 설정에서 값을 집어넣습니다.
그래서 파일만 다른 도구로 가져가면 그 값들이 **아예 안 들어갑니다.**

| 항목 | URDF 에 있던 값 | MJCF 파일에 있던 값 | **우리가 실제로 돌리는 값** | URDF 로 표현 가능? |
|---|---|---|---|---|
| 관절 한계 | ✅ 맞음 | ✅ 맞음 | 같음 | 예 — 이미 맞았음 |
| 최대 토크(effort) | ✅ 120 / 60 | (액추에이터 없음) | 120 / 60 | 예 — 이미 맞았음 |
| **점성 감쇠** | **없음** | 0.02 / 0.2 (자리표시자) | **0.0275 / 0.0252** | **예 — `<dynamics damping>`** |
| **마른 마찰** | **없음** | **아예 없음** | **0.519 / 0.251** | **예 — `<dynamics friction>`** |
| **회전자 관성(armature)** | **없음** | 0.0005 / 0.005 (자리표시자) | **0.0773 / 0.0638** | **아니오 — 규격에 자리 없음** |
| 구동기 자체 | — | **0개** | 12개 위치 서보 | 아니오 (제어기) |
| 위치 제어 게인 | — | — | 150 / 220, 감쇠 6 | 아니오 (제어기) |
| 토크-속도 곡선 상한 | — | — | 실측 22~37점 | 아니오 |

**회전자 관성이 실제의 1/100~1/15 자리표시자**였고 **마른 마찰은 0** 이었습니다. 그 파일을
그대로 다른 시뮬레이터에 물리면, 관절이 거의 무저항으로 도는 **전혀 다른 로봇**이 됩니다.
우리가 벤치에서 겪은 "세기 5로는 정지마찰을 못 이겨 5도 명령에 0.04도" 같은 현상이 그쪽에서는
아예 안 나타납니다.

## §2 무엇을 고쳤나

`tools/robot_model/write_motor_params_xml.py` (2026-09-10 에 **MJCF 용으로 이미 있던 도구**)에
URDF 처리를 붙였습니다. 값의 정본은 그 파일의 `SETS` 하나뿐이라, 새로 만들지 않았습니다.

```
python3 tools/robot_model/write_motor_params_xml.py --in-place --sidecar \
    --xml pygmalion_locomotion/assets/pygmalion_v2/*proxyfix*.urdf
```

* **`<dynamics damping= friction=/>`** 를 구동 관절마다 넣었습니다 — **표준 URDF** 라 어느
  도구든 읽습니다. URDF 의 `friction` 은 MuJoCo 의 `frictionloss` 와 같은 뜻입니다.
* **회전자 관성은 규격에 자리가 없어** 관절마다 **주석**으로 적고, 옆에
  `<이름>.motor_params.json` 을 같이 냈습니다. 규격에 없는 태그를 지어내면 엄격한 파서가
  파일 전체를 거부할 수 있어서, 읽는 쪽이 골라 쓰게 뒀습니다.
* **두 번 돌려도 같은 결과**가 나옵니다(직전에 쓴 것부터 걷어냄). 처음엔 주석이 쌓여서
  고쳤습니다.

고친 파일 **9개** (`*_proxyfix*.urdf`: LegOnly·FullDoF·SemiFullDoF 의 loop/비loop, 그리고
접두어 없는 원본 둘). 전부 XML 파싱 검사를 통과했습니다.

**모델 생성기(`build_robot.py`)에도 넣었습니다** — 안 그러면 다음에 다시 만들 때 조용히
사라집니다. 이 계통에서 반복해 겪은 실패라 생성기까지 손댔습니다.

## §3 아직 남은 것 — 속도 한계

URDF 의 `velocity` 가 전 관절 **20** 으로 같은 자리표시자입니다. 실측은 RS04 무부하
**19.9 rad/s**, RS03 **20.94 rad/s** 로 다릅니다. 다만 **숫자 하나로는 실제 한계를 못
적습니다** — 진짜 한계는 토크에 따라 달라지는 **토크-속도 곡선**이고, 그건 URDF 에 자리가
없습니다. 그래서 건드리지 않고 여기 적어 둡니다. 옮겨 갈 때는 sidecar 와 `Motor_Spec/` 의
실측 곡선을 같이 가져가야 합니다.

## §4 MJCF 는 어떻게 하나

MJCF 원본 파일에도 같은 자리표시자가 남아 있습니다(armature 0.0005 / 0.005, damping
0.02 / 0.2, 구동기 0개). 같은 도구로 `--in-place` 없이 돌리면 값이 박힌 **사본**이 나오고,
원본은 mjlab 이 주입하는 방식 그대로 둘 수 있습니다. **어느 쪽을 정본으로 할지는 정하지
않았습니다** — 학습 쪽 계약을 바꾸는 일이라 여쭙고 하겠습니다.
