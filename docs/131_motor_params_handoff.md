## 2. 지금 코드에 들어 있는 값

`pygmalion_constants.py` 의 `MOTOR_MEAS` 를 **2026-09-10 재측정값으로 바꿨습니다.**
값 묶음을 여러 벌 두는 선택기는 쓰지 않습니다 — 쓰는 값은 한 벌입니다.

참고로 지금까지 있었던 값과 원본은 이렇습니다. 이 표는 **기록용**이고 코드에는 없습니다.

| | RS04 (J / b / tc) | RS03 (J / b / tc) |

## 3. ★ 왜 이렇게 차이가 나나 — **어긋나는 건 관성 하나뿐입니다**

| RS04 | 연구원 | 2026-09-10 재측정 | 차이 |
|---|---|---|---|
| frictionloss | 0.526084 | **0.519** | **1.3%** ✅ |
| damping | 0.026008 | **0.0275** | **5.7%** ✅ |
| **armature** | **0.030605** | **0.0773** | **2.53배** ❌ |

| RS03 | 연구원 | 2026-09-10 재측정 | 차이 |
|---|---|---|---|
| frictionloss | 0.285370 | 0.251 | 12% |
| damping | 0.022342 | 0.0252 | 13% |
| **armature** | **0.015265** | **0.0638** | **4.18배** ❌ |

두 사람이 **독립적으로 재서 마찰과 점성은 거의 같은 값**이 나왔습니다. 어긋나는 것은
**관성** 하나입니다.

★ **이것이 중요한 이유**: 단위 착오나 감속비 반사 문제라면 **세 값이 같은 배수로** 틀려야
합니다. 그렇지 않으므로, 원인은 **관성을 뽑아내는 방법**에 있습니다.

### 재측정 쪽 근거 (맞춤 없이 뉴턴 법칙만)

1. **마찰 소거 뺄셈** — 같은 속도 구간을 서로 다른 다섯 토크로 지나가게 하면 마찰이 식에서
   사라지고 **토크 대 가속도 직선의 기울기가 곧 관성**입니다.
   **77.3 ± 0.6 g·m², 결정계수 0.9994.** 덤으로 절편(그 구간의 마찰)이 0.648 로, 따로 잰
   마찰식이 예측하는 0.643 과 1% 안에서 맞습니다.
2. **타성 감속** — 전제가 전혀 다른 방법(토크를 0으로 놓고 마찰만으로 세움). **73~81 g·m².**
   두 방법이 합칩니다.
3. ★ **공진 자리** — 세기 `kp` 로 붙잡힌 모터는 √(kp ÷ 관성) 에서 공진합니다.
   **맞춤도 가정도 없이 "어디서 흔들리기 좋아하는가"만 보면 됩니다.**

   | 관성 값 | 예측 공진 (kp=20) | 실물 실측 |
   |---|---|---|
   | 연구원 0.030605 | **4.07 Hz** | |
   | 재측정 0.0773 | **2.56 Hz** | **2.48 Hz** |

   실물이 2.48 Hz 에서 공진합니다. 30도 진폭에서는 실물 2.121 Hz, 재측정값을 넣은
   시뮬레이터도 **2.121 Hz** 로 소수점까지 같습니다.
4. **계단 응답 세 지표 동시 적중** — 남은 오차 0.723 대 실물 0.678, 지나친 양 43.2% 대
   41.2%, 90%까지 148 밀리초 대 149.1. 전부 7% 안.

### 연구원 쪽에서 그럴 수 있는 이유 (짐작, 방법을 못 봤습니다)

다중사인 자료에 모형을 **맞추는** 방식이면 **가정한 지연에 관성이 극도로 민감**합니다.
같은 방식을 2026-09-09 에 시도했을 때, 지연 가정을 0 → 30 밀리초로 바꾸는 것만으로
armature 가 **0.14 ↔ 0.99 로 7배** 요동쳤습니다(`2026-09-09_motor_sysid_attempt.md` §4).
보고된 ±0.000109 는 **그 맞춤 내부의 불확실도**라 이런 치우침을 잡아내지 못합니다.

★ **확정하지 않았습니다.** 연구원 쪽 원자료와 방법을 보면 몇 분 안에 갈립니다. 그 전까지는
코드에 **재측정값**이 들어가 있고, 연구원 값은 2번 표에 기록으로 남겨 두었습니다 — 되돌리려면
`MOTOR_MEAS` 두 줄만 바꾸면 됩니다.

## 4. 무엇을 바꿨나

### 4-1. 설정 (`pygmalion_constants.py`)

`MOTOR_MEAS` 를 **2026-09-10 재측정값으로 교체**했습니다(2번). 값이 한 벌이므로 고르는
스위치는 없습니다. `PYG_MOTOR_MEAS=0` 은 그대로입니다.

### 4-2. 값이 박힌 MJCF 사본

지금 모델 파일에는 주 관절의 세 값이 **적혀 있지 않습니다.** mjlab 이 불러올 때 액추에이터
설정에서 집어넣습니다. 그래서 **XML 만 열어 보면 값을 알 수 없고**, mjlab 이 아닌 도구로
그 파일을 불러오면 **값이 아예 안 들어갑니다.**

`tools/robot_model/write_motor_params_xml.py` 로 값이 박힌 사본을 만들었습니다.
**원본은 건드리지 않습니다.**

| 새 파일 | 바탕 | 값 묶음 |
|---|---|---|
| `pygmalion_v4_printed_loop_bench20260910.xml` | v4 폐루프 (최신) | bench-2026-09-10 |
| `pygmalion_v3_printed_loop_bench20260910.xml` | v3 폐루프 (정책 15개가 학습한 모델) | bench-2026-09-10 |
| `SemiFullDoF_..._v30_proxyfix_loop_bench20260910.xml` | legonly 계열 | bench-2026-09-10 |

관절 대응(액추에이터 설정과 같음): `*_hip_pitch/roll/knee/waist_yaw` → RS04,
`*_hip_yaw` · `*_crank_A/B` · `*_shoulder_*` → RS03. 발목 힌지·로드·발가락은 **수동**이라
건드리지 않습니다. 세 파일 모두 MuJoCo 로 불러 값이 들어갔는지 확인했습니다.

```
python3 tools/robot_model/write_motor_params_xml.py --set bench-2026-09-10 \
        --xml <원본.xml> [<원본2.xml> ...]
```

## 5. 무엇을 하면 되나 — 권하는 순서

1. **연구원 원자료를 받아 관성 이견부터 닫으십시오.** 이게 제일 큽니다. 공진 자리 하나만
   봐도 갈립니다 — 세기 20 에서 그 모터가 2.5 Hz 에서 흔들리는지 4 Hz 에서 흔들리는지.
2. 지금 코드에는 **재측정값이 들어가 있습니다.** 연구원 값으로 되돌리고 싶으면 `MOTOR_MEAS`
   두 줄을 바꾸면 됩니다(2번 표).
3. **제어 이득을 다시 잡으십시오.** 관성이 커지면 같은 감쇠비를 내는 `damping`(Kd)이
   √배수만큼 커야 합니다.

   | | 예전 코드 값 | 연구원 값 | **지금 들어간 값** |
   |---|---|---|---|
   | 무릎 armature | 0.016333 | 0.030605 | **0.0773** |
   | 같은 감쇠비를 위한 Kd 배수 | 1.0 | 1.37배 | **2.18배** |

   지금 무릎은 `stiffness 220 / damping 6.0` 입니다. 값을 바꾸고 이득을 그대로 두면
   **덜 감쇠되어 출렁**이고, 정책이 나빠진 것처럼 보입니다. **값이 틀려서가 아니라 이득이
   안 맞아서입니다.**
4. **모터만 세운 대조로 먼저 확인** — 학습 없이 몇 초면 끝납니다(6번).
5. **짧은 A/B 학습** — 같은 시드·같은 보상, `MOTOR_MEAS` 만 다르게(파일을 되돌려서).
6. 그 뒤에 본 학습.

### 같이 손봐야 하는 것

* **발목 반사값** — 발목 두 관절은 `MOTOR_MEAS` 를 직접 안 쓰고 `ankle_rp_envelope.json`
  에서 읽습니다. 모터 값이 바뀌면 `tools/robot_model/ankle_rp_envelope.py` 를 다시 돌려
  json 을 갱신해야 합니다. **안 하면 발목만 옛 값으로 남습니다.**
* **무부하 속도** — `NO_LOAD_RPM = {"RS04": 200, "RS03": 200}`. 벤치 실측은 **227 rpm**
  이었고, 이는 전원이 48 볼트가 아니라 약 57 볼트라는 뜻입니다(추론). 전원 전압을 정한
  뒤에 맞추십시오. 57 볼트는 모터 과전압 고장 문턱(60)에 너무 가까워 **48 볼트로 낮추기를
  권합니다** — 그러면 지금 곡선이 맞습니다.
* **아직 안 잰 모터** — 발목의 RS03·RS00 은 안 쟀습니다. RS03 의 점성이 모형보다 작은
  것으로 잘못 알았다가 정정한 일이 있으니(`2026-09-10_rs03_friction_correction.md`),
  **비율을 짐작으로 옮기지 마십시오.**
