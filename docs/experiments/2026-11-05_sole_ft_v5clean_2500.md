## 3. 평가 결과

평가: 3090 GPU, 지형 6종, 환경 32개, 명령 9개 × 15 초, 시드 0, 무작위화·잡음·밀기 없음. 도구 `tools/foot_sole/v5cap_compare.py`, 결과 `study/compare_v5clean_retrain_{51000,52498}.json`. 넘어진 환경 수(29조각 → 캡슐):

| 지형 | 저장본 51,000 | 저장본 52,498 |
|---|---|---|
| 평지 | 0 → 17 | 0 → 0 |
| 굴곡 1~2 cm | 0 → 6 | 1 → 0 |
| 6° 경사 + 굴곡 | 23 → 19 | 5 → 10 |
| 돌 2 cm | 0 → 15 | 7 → 32 |
| 돌 1 cm | 1 → 14 | 14 → 32 |
| 자갈 3~8 mm | 0 → 18 | 0 → 31 |

접촉 지표는 캡슐이 좋다: 침투 최대 8~15 mm(29조각 12~18 mm), 대부분의 지형에서 미끄러짐 P95 감소. 반면 발끝·뒤꿈치 두 점만 닿는 시간 비율(`split_frac`)은 0.06 → 0.45~0.61.

시드 잡음 기준: 29조각 발만 시드 43 대 44(`compare_v5fullm_seed_*.json`)로 보면 경사 넘어짐이 23 대 8(51,000), 5 대 5(52,498), 평지·굴곡은 0~1개 차이.

## 4. 판정과 한계

- **판정:** 이 학습 조건(49,999에서 2,500 반복)에서 캡슐 발은 돌·자갈에서 29조각 발보다 불안정한 정책을 만들었다. 접촉 지표만 보면 캡슐이 낫지만, 정책 성능은 아니다. 캡슐 발을 채택할 근거가 없다. 형상 훑기(Stage-1)는 29조각 발로 계속한다(docs/185 §7 권고와 같다).
- **저장본 사이 변동이 크다.** 평지에서 51,000은 17개 넘어지고 52,498은 0개. 시드 1개라 "항상 나쁘다"고 말할 수 없다.
- **원인은 확인하지 않았다.** 후보: 두 점 접촉(`split_frac`) 걸음으로 수렴, 캡슐 줄 위에서 구르는 윤곽, 접촉 버퍼 문제(학습 로그에 넘침 경고는 없음). 어느 것도 시험하지 않았다.
- GPU 평가만이다. CPU 결과와 섞지 않았다.
