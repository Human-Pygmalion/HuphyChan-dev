## §0 왜 이 학습을 하는가

사용자 질문 *"mjcf 변경 전에는 잘 서있었나?"* 에 답하려고 세대별로 같은 조건(명령 0, 시작 자세
흔들림 없음, 2026-09-03 v2 점검과 동일)에서 재 보니:

| 정책 | 몸통 높이 흔들림 | 이동 | 방향 변화 | **발 뗀 시간** |
|---|--:|--:|--:|--:|
| v3 완주본 | 9.55 mm | 0.113 m | 45.3° | 2.50 s |
| **v4 완주본** | **2.16 mm** | **0.020 m** | **3.5°** | **0.00 s** |
| **v5 완주본** | 11.43 mm | 0.208 m | 16.7° | **7.28 s** |

**v4는 발을 한 번도 떼지 않는다. v5만 나빠졌다.** 흐트러진 시작으로 재도 같다
(v3 4.41 / v4 4.28 / **v5 9.69초**). v5의 변인은 `PYG_REL_HEADING` 0.3 → 0.8 하나뿐이므로,
**그것이 제자리 서기를 망쳤다**는 가설이 선다. 방향을 자주 맞추도록 배우면서 서 있어야 할 때도
발을 디디는 버릇이 붙은 것으로 보인다.

**로봇 모델 이름 바꾸기는 원인이 아니다**: 전후 모델 전수 대조 불일치 0건, 리셋 발 위치 차
0.00e+00 m, v5가 학습한 환경의 폐루프 0.0000 mm. 비틀린 정지 자세 자체는 이름 바꾸기 9일 전
(2026-09-03 v2 `model_700`: hip_yaw −20.02 / −26.14°)부터 기록돼 있는 **별개 문제**다.

## §1 설계 — 2×2 가 완성된다

| | 정지 환경 0.1 | 정지 환경 0.3 |
|---|---|---|
| **방향 유지 0.3** | **v4** — 잘 섬, 엉덩이회전 좌우차 +50.8 % | **v7 ← 이번 런** |
| **방향 유지 0.8** | **v5** — 못 섬, 좌우차 +7.5 % | **v6** — 진행 중 |

**변인: `PYG_REL_HEADING` 0.8 → 0.3** (v6 대비 한 줄). v6과 나란히 놓으면 정지 환경 비율을
0.3으로 고정한 상태에서 방향 유지 비율만 바뀌므로, **제자리 서기를 망친 것이 방향 유지 비율인지**
깨끗하게 갈린다. v4와 나란히 놓으면 방향 유지를 0.3으로 고정한 채 정지 환경 비율만 달라진다.

읽는 법:

* v7이 잘 서고 v6이 못 서면 → **방향 유지 비율이 범인**. 좌우 대칭 성과(50.8 → 7.5 %)를
  지키려면 둘을 분리해야 한다(예: 방향 되먹임은 유지하되 정지 환경에서만 끄기).
* v6도 v7도 잘 서면 → 정지 환경 비율만 올려도 충분하다. v6을 채택한다.
* 둘 다 못 서면 → 정지 자세 추종 항의 허용 오차를 관절별로 다시 주는 쪽으로 간다(연구노트 선행).

**v6과 같게 유지하는 것**: `PYG_REL_STANDING=0.3`을 포함해 로봇 모델·모터 값·세기·보상 항과
가중치 전부·커리큘럼·도메인 무작위화·시드 42·환경 수 16384.

## §1b 시간 예산 (사용자 지시)

사용자가 **약 6시간**을 허용했다. v5 실적으로 6시간이면 **1단계(약 4,100회)가 끝난다**
(v5: 03:02 발사 → 08:07 1단계 졸업, 5시간 5분). 정지 판정에는 도메인 무작위화가 필요 없으므로
**1단계 저장본으로 판정**하고, v4·v5·v6의 1단계 저장본과 **같은 반복 수에서** 비교한다.
