**§1b-3. ROM 한계·액션 창** (모델 XML range · soft 한계 = 중심±0.5·range×0.9 (mjlab `Entity` 규약) · 액션 clip = env.yaml `actions.joint_pos.clip` · 창 = clip 폭 · default = 액션 0 자세)

## 3c. ★게이트 배터리 판정 (gen2p1_fc, 15s dwell 전박스 — 2026-07-12 19:40)
| 게이트 | 기준 | 실측 | 판정 |
|---|---|---|---|
| 측방 | vy ±1.0 ≥60% | **+1.0→61% · −1.0→96%** | ✅ **최초 통과** (hip_roll std 0.4 효과 — 전 계보 31~58%였음) |
| stall | 0.7 달성 ≥60% | 0.75→**84%** (구 41~44%) | ✅ 통과, 단 ⚠아래 |
| knee 속도 | ω P99.9 ≤19.9 | **15.6** (max 26.5=낙상 스파이크) | ✅ |
| GRF | ≤1.6BW | 1.44BW | ✅ |
| 고속 | 2.5 ≥85% | **67%** (+1.5도 43% 구멍) | ❌ |
| 부하 회귀 | knee 클립 내 | P99 **120=클립**·클립체류 2.04%·RMS 121% | ❌ |

- **부수 대승**: 후진 전구간 회복(−2.0 109%·−1.75 112%·−0.75 117% — bent P1은 39~66%였음).
- ⚠**stall 벌점 게이밍 시그니처**: cmd 1.5→0.64(43%) — 정지(<0.15 m/s)만 벌점이라 **"살살 걷기"(creep)로 우회**한 것으로 보임. 확정 시 수정안: 절대 임계 대신 **상대 임계** $\lvert v\rvert < 0.3\lvert cmd\rvert$.
- knee 클립체류 2%는 고속전진 아님(전진만의 P99 95.6) — 낙상 15회+combo 과도 기인 추정.
- **판정: P2 계속 진행** — bent 계보 선례상 P1의 블록 널뛰기·낙상·포화는 P2(DR)가 크게 완화(bent P1 39~174% 널뛰기 → bentp2 79~97%·낙상 0). **최종 게이트는 gen2 P2 측정으로 판정**, 그때도 고속/knee 실패면 stand_still_penalty 상대임계 ablation.
