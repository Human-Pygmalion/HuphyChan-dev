## §0 왜 이 학습을 하는가

사용자 지시: *"외력 다양하게 버티도록, 초기자세 틀려도 잘 버티도록 더 학습해줘."*

v7 은 명령 0 만 주고 서기를 배웠고 **750 반복만에 수렴**했습니다 (속도추종오차
1.07 → 0.010, 넘어짐 0, 테더 없이 140초 서 있음). 그런데 그것은 **아무 방해가 없는
조건에서만** 잘하는 정책입니다. 확인한 설정이 이렇습니다.

```
PYG_DR_START_ITER = 100000000     외력(push)이 1억 반복 뒤 시작 = 사실상 꺼짐
position_range    = (0.0, 0.0)    초기 자세가 항상 키프레임 그 값, 흔들림 0
```

밀면 넘어지고, 손으로 내려놓아 자세가 틀어져 있으면 못 일어납니다.

### §1a 새로 만든 손잡이 두 개

`velocity_env_cfg.py` 의 리셋은 **모든 관절을 키프레임 정확히 그 값**에 놓고
(`position_range = (0.0, 0.0)`) 몸통을 똑바로 세웁니다. 환경변수가 없어서 바꿀 방법이
아예 없었습니다. `config/pygmalion/env_cfgs.py` 에 둘을 더했습니다.

```
PYG_RESET_JOINT_NOISE [rad]   관절마다 키프레임에서 균등하게 ± 만큼 어긋나 시작
PYG_RESET_TILT        [rad]   몸통이 롤/피치로 균등하게 ± 만큼 기울어 시작
```

둘 다 **안 주면 꺼집니다.** 기존 런은 글자 그대로 그대로 재현됩니다.

외력은 이미 있었습니다 — `push_robot` 이 1~3초마다 속도를 툭 칩니다
(앞뒤·좌우 ±0.7 m/s, 상하 ±0.4, 회전 ±0.52~0.78 rad/s). 다만 1단계에서 꺼져 있었을
뿐입니다.

## §2 무엇을 보고 판정하는가

| 항목 | v7 값 | 목표 |
|---|--:|---|
| 넘어짐 비율 | 0.000 (외력 없음) | **외력 켠 뒤에도 0.01 이하** |
| 명령 0 에서 몸통 기울기 | 0.1° | 3° 이내 |
| 크랭크 토크 (정격 대비) | 최대 70 % | **50 % 이하** ← v7 의 약점 |
| 엉덩이좌우 토크 | 49~58 % | 40 % 이하 |

★ v7 은 발목 크랭크를 목표와 20~25° 어긋나게 **눌러 놓는 방식**으로 버텼고 토크가
정격의 70 % 였습니다. 외력을 넣으면 그 여유가 없으므로, 이 값이 내려가는지가 이번
런의 실질 판정입니다.

사용자 지시: *"DR 커리큘럼으로 더 세게 넣어. 실제 사례조사해봐."*

| 항목 | 우리(전) | 참고 사례 | **우리(후)** |

넓어야 합니다.

아직 없는 것: **행동 지연**과 **PD 게인 랜덤**. 조사한 구현들이 다 쓰는데 우리에겐
이벤트 자체가 없습니다. 새로 만들어야 해서 이번엔 안 넣었고 열린 일로 남깁니다.
