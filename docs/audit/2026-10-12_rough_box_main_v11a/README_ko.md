### 0.3 작성 규칙

이 문서는 ASD-STE100 의 원칙을 한국어에 맞춰 따른다.

- 한 문장에 한 가지 내용만 쓴다. 설명 문장은 짧게 쓴다.
- 능동형으로 쓴다. 사실은 현재형, 지난 사건은 과거형으로 쓴다.
- 기술 용어(PPO, MJCF, 아마추어 등)는 그대로 쓴다. 처음 나올 때 뜻을 붙인다.
- 긴 문장 대신 표와 목록을 쓴다.
- "미검증" 은 이 감사가 증명하지 못한 내용이다.
- "출처 없음" 은 값이 어디서 왔는지 기록이 없는 경우다.

### 1.2 지형

`PYG_BOX_TERRAIN=1` 이 `BOX_TERRAINS_CFG` 를 고른다 (`MJ/src/mjlab/terrains/config.py:336-352`, 커밋 `9af9bae3`).
모든 지형을 상자로 만든다. 높이 지도(heightfield) 지형은 없다.

이유: MuJoCo-Warp 의 높이 지도 접촉에서 걷는 발이 미끄러졌다. 완전히 평평한 높이 지도에서도 그랬다.
평평한 높이 지도에서는 64 대 중 28~43 대만 계속 걸었다. 평평한 상자에서는 64 대 모두 계속 걸었다.
출처: `docs/experiments/2026-10-11_flat_vs_rough_policy_compare.md` §2b; `docs/162_next_plan_rough_policy.md` 단계 2.

| 하위 지형 | 비율 | 난이도 t (= 행 번호 / 9) 에 따른 모양 |
|---|---|---|
| 평지 | 0.2 | 변화 없음 |
| 피라미드 오르는 계단 | 0.2 | 단 높이 0.1·t m, 단 폭 0.3 m, 전체 높이 0.6·t m |

| 기울어진 판 | 0.2 | 1.0 m 판, 기울기 ±15·t 도 안에서 균등, 높이 잡음 ±0.1·t m |

### 1.9 이어 학습

1. 발사 스크립트가 부모 저장본에서 행위자만 읽는다. 평가자, 최적화기, 반복 번호는 새로 시작한다.
   이유: 험지 평가자는 입력이 269 개다. 평지 부모의 평가자는 입력이 더 적다.
   출처: `MJ/analysis/train_actor_warmstart.py:23-42`.
2. `PYG_FRESH_STEPS=1` 이 읽은 뒤 환경 걸음 수를 0 으로 되돌린다. 걸음 수에 묶인 일정이 모두 처음부터 다시 시작한다.
   출처: `train_actor_warmstart.py:47-51`; 콘솔 273 줄.

### 3.3 질량 무작위화 파일

파일: `tools/robot_model/fusion_snapshots/v30_inspection/mass_dr_legonly_fastener50_prototype-tempmass.json`. 스크립트: `tools/robot_model/mass_dr.py`.

   | 종류 | σ | 근거 |
   |---|---|---|

2. 체결구 항목("fastener50")을 더한다. CAD 에는 실제 나사의 50~100 % 만 들어 있을 수 있다.
   스크립트는 c ~ U(0.5, 1.0) 을 뽑고 CAD 나사 질량에 1/c 를 곱한다. 출처: `docs/114_huphy_proxyfix_rotation_dr_audit.md` §5.

### 3.4 엔코더 영점 오차의 작동 방식

1. 초기화 때 관절마다 오차를 더한다.
2. 행동 처리가 목표에서 오차를 뺀다 (`actions.py:222-224`).

따라서 이 오차는 구동 목표의 어긋남이다. 센서 값의 어긋남이 아니다 (지적 F2).

### 5.2 값을 정한 방법

**엉덩이·무릎 (150/6, 220/6): 참조 로봇 게인 × 질량비.**
1. Unitree G1 과 K-Bot 의 게인을 가져온다.
2. 질량비 51.5 / 35 = 1.47 을 곱한다.
3. 엉덩이: G1 Kp 100, K-Bot Kp 100 → 150. 무릎: G1 Kp 150 → 220.
4. Kd 6 은 G1 환산값(3)과 K-Bot 환산값(15) 사이다.

출처: `CONST:672-676, 736-739, 746-749`; `docs/mujoco/2026-07-06_kp_kd_history.md` §1a.
이 값들은 관성으로 계산하지 않았다.

**크랭크 모터 (22.27/1.41): 발목 게인을 연결 기구로 옮김.**
1. 목표 발목 게인: 28.5 N·m/rad, Kd 1.81 (Unitree G1 발목 사양, `CONST:627-628`).
2. 크랭크 2 개가 발목 축 하나를 지렛대 비 r = 1.25 로 움직인다 (CAD 값, `docs/87`).
3. 가상일 원리: K_발목 = 2 K_크랭크 / r². 따라서 K_크랭크 = K_발목 × r² / 2.
4. Kp = 28.5 × 1.5625 / 2 = 22.2656. Kd = 1.81 × 1.5625 / 2 = 1.4141.

출처: `CONST:713-721`.

**실제 발목 강성:** 조사 E 가 고리 야코비안으로 계산했다.
