# 새 마찰 무작위화 범위와 응답 기반 시스템 식별 방법 (할 일 #210)

2026-11-04 · 사용자 질문: "새 발과 넘어지기 시작하던 마찰계수를 기점으로 새 마찰계수와 DR의 적절한 범위를 도출할 수 있나? 응답을 통해 System Identification 을 조정하는 방법론을 찾아 달라."
앞 문서: `docs/187`(마찰 범위·넘어짐 벽), `docs/189`(실기 대 Sim: 서기 때 발이 붙는 차이), 조사 원문 `docs/research_raw/2026-11-04_friction_sysid_methods_sources.md`.

용어: **DR**(domain randomization, 영역 무작위화)은 학습 중 시뮬레이터 값을 무작위로 바꾸는 것이다. **시스템 식별**(system identification)은 실물의 응답을 재서 시뮬레이터 값을 맞추는 것이다. **사후분포**(posterior)는 실물 데이터를 본 뒤 "이 값일 가능성이 높다"를 나타낸 분포이다.

# 0. 결론

1. **지금 가진 데이터로 DR 범위를 확정할 수는 없다. 잠정 범위와 확정 절차를 낸다.** 이유: 실기 마찰계수를 잰 값이 아직 없다. 걷기 기록은 마찰을 건드리지 않는 움직임이라 마찰계수를 식별하지 못한다(§2).
2. **잠정 DR 범위: 마찰 0.3 ~ 1.6 (새 발 기준).** 아래 한계는 지금 DR(0.3~1.2)의 값을 유지한다. 위 한계는 1.2 에서 1.6 으로 올린다. 근거는 §1이다. 이 값은 실측이 오기 전의 보험이다.
3. **넘어짐 시작점은 "DR 상한"이 아니라 "정책이 견디는 한계"이다.** 기존 발은 1.75 에서 벽이 있다. 새 발은 3.0 까지 벽이 없다. DR 상한은 이 벽보다 낮게 두고, 실측으로 정한 값에 여유를 더해서 정한다.
4. **정말 식별해야 하는 것은 마찰계수 하나가 아니다.** 실기만 서 있을 때 발이 붙어 있다(`docs/189`). Sim은 마찰 0.6 인데도 옆힘 대 수직힘 비 0.11 에서 발이 기어간다. 그러므로 식별 대상은 **정지 마찰계수 + 접촉이 얼마나 단단한가(접촉 강성, solref)** 두 가지 묶음이다. 마찰계수만 맞추면 서기 폭 차이는 안 없어진다(`docs/178` §4-5, `docs/187` §3).
5. **방법: 3단계 식별.** (가) 발 밑창과 카펫을 따로 재는 직접 측정, (나) 로봇을 서게 한 채 엉덩이 좌우(hip_roll) 목표를 천천히 올려 **미끄러지기 시작하는 순간**을 재는 응답 시험, (다) 그 응답을 Sim 재생과 맞춰 마찰·접촉 강성의 사후분포를 구하는 시뮬레이션 기반 추론. 사후분포의 구간에 여유를 더한 것이 확정 DR 범위이다(§4).
6. **아직 실행하지 않았다.** 이 문서는 방법과 잠정 범위이다. 실기 시험 3가지가 필요하고, 그 전에 Sim에서 식별 가능성을 먼저 확인할 수 있다(§5).

# 1. 잠정 범위를 낸 근거

| 사실 | 값 | 출처 |
|---|---|---|
| 지금 학습 DR | 0.3 ~ 1.2 (균일, 절대값) | `docs/187` §1 |
| 기존 상자 발 + 49999 정책, 마찰별 넘어짐 | 1.5 까지 0/32, 1.75 에서 2/32, 2.0 에서 26/32 | `docs/187` §4 |
| 새 발(v5) + 49999 정책 | 3.0 까지 0/32 | `docs/187` §4 |
| 0.3 ~ 1.5 에서 평균 양발 간격 | 기존 229~241 mm, 새 발 217~226 mm. 마찰로 모이지 않음 | `docs/187` §3 |
| 문헌의 배포용 마찰 범위 | 대략 0.2 ~ 1.7 (제3자 문서, 등급 S) | `docs/research_raw/2026-11-04_foot_friction_carpet_rubber_sources.md` |
| 고무 밑창 + 카펫의 실측값 | **없음** (검색 6회) | 같은 문서 |
| 서 있는 동안 필요한 마찰계수 하한 | 약 0.12 (hip_roll 만 센 어림값) | §2 |

- **상한을 1.6 으로 하는 이유.** 기존 상자 발의 벽(1.75)보다 낮고 문헌 범위(1.7)와 비슷하며, 지금 상한 1.2 에서 1.33 배 올린 값이다. 새 발은 3.0 까지 견디므로 이 상한에서 넘어짐 위험은 시뮬레이션에서 보이지 않는다. 학습 정책이 이 범위를 보면 벽이 위로 이동한다고 기대하지만, 이 기대는 재학습 시험 전에는 확인되지 않았다.
- **하한은 0.3 을 유지한다.** 새 발과 기존 발 모두 0.3 에서 0/32 이다. 하한을 내릴 근거(젖은 바닥 등)는 지금 없다.
- 기존 발에서는 벽 때문에 상한을 1.5 이하로 두는 것이 안전하다. 새 발 모델로 재학습할 때만 1.6 을 쓴다.

# 2. 지금 기록이 마찰을 식별하지 못하는 이유

- **걷기 기록은 약한 자극이다.** 걸을 때 발이 지면에 미끄러지지 않는 범위에서 움직인다. 미끄러지지 않으면 마찰계수는 응답에 나타나지 않는다. 마찰계수는 "미끄러지는 순간"에만 응답을 바꾼다.
- **Sim에서도 확인됐다.** 마찰을 0.3 에서 3.0 으로 바꿔도 걷기 폭이 같다(`docs/187`). 폭, 목표 오차 같은 지표는 마찰에 둔감하다.
- **실기 기록에서 얻는 것은 하한뿐이다.** 서 있을 때 발이 50 초 동안 움직이지 않았고 hip_roll 이 약 10 N·m 를 밀고 있었다. 발 하나가 옆으로 받는 힘은 약 13 N(10 N·m ÷ 다리 길이 0.8 m)이고 발 하중은 약 116 N 이다. 그러므로 정지 마찰계수는 약 0.12 이상이다. 발목·무릎이 내는 옆힘은 빼고 센 어림값이다. 걷기에서는 미끄러짐을 볼 방법이 없다(기록에 발 위치 기준이 없다).
- **식별하려면 일부러 미끄러뜨려야 한다.** 이것이 §3-(나)이다.

# 3. 방법: 3단계 식별

## (가) 직접 측정 (로봇 없이, 값이 싸고 가장 믿을 수 있음)

- 실제 신발 밑창 조각을 실제 카펫에 놓고 **기울임판 시험**(미끄러지기 시작하는 각도 θ 에서 μ = tan θ)과 **당김 시험**(힘 게이지로 시작 힘 대 하중)을 한다.
- 압력 8 kPa 와 15 kPa 두 가지(`docs/187` §5). 돌기 무늬 방향 3가지(미끄럼 방향이 돌기와 평행, 직각, 45°).
- 얻는 것: 정지 마찰계수 μs 의 구간, 방향 의존. **이 값은 사후분포의 사전 범위가 된다.**
- 한계: 카펫 털이 걸리는 효과와 로봇 발의 하중 분포는 조각 시험으로 다 재현되지 않는다.

## (나) 로봇 응답 시험: 서게 한 채 미끄러지는 순간 재기

서 있는 자세에서 양쪽 hip_roll 목표를 **바깥으로 천천히 같이 올린다**(예: 0.05°/s). 발이 붙어 있는 동안은 목표 − 측정 오차가 목표와 함께 커지고(= 옆힘이 커진다), 발이 미끄러지는 순간 측정이 갑자기 따라가면서 오차가 줄어든다.

- **재는 것**: 모든 관절 목표·측정(100 Hz), 가능하면 모터 전류. 발 사이 폭은 기록의 순기구학으로 구한다(`tools/sim2real/walk/stance_fk.py`).
- **계산**: 미끄러짐 시작 순간의 관절 토크 τ = Kp × (목표 − 측정)로 구한다. Kp 가 설정값과 같음은 전류로 확인했다(131/135, R² 0.98, `docs/178` §4-4). 토크에서 발 옆힘 Ft 는 정역학 Ft = J⁻ᵀ(τ − 중력 보상)로 구한다(J = 발 접촉점의 자코비안, MuJoCo 로 계산). 수직힘 Fn 은 몸무게 절반(로봇 질량을 실제로 달아서 사용).
- **얻는 것**: 정지 마찰계수 μs = Ft / Fn (미끄러짐 시작). 이어서 미끄러지는 동안 힘이 내려가는 크기에서 운동 마찰 μk 의 대략값.
- **이 시험이 중요한 이유**: 서기 폭 차이(`docs/189`)를 직접 재현한다. 같은 시험을 Sim에서 하면 Sim의 발이 어느 Ft/Fn 에서 기어가는지 나온다.
- 왼발·오른발이 같이 미끄러지므로 한 발씩 따로는 못 잰다. 한 발만 들고 하는 변형은 균형 문제가 커서 권하지 않는다.

## (다) 응답을 맞추는 계산: 시뮬레이션 기반 추론

모든 방법의 공통 구조는 같다: **시뮬레이터 파라미터 θ 를 바꿔 가며 실물과 같은 입력으로 돌리고, 응답이 실물과 얼마나 닮았는지로 θ 의 가능성을 평가한다.**

| 방법 | 하는 일 | 이 프로젝트에서 장단점 |
|---|---|---|
| 점 추정 (CMA-ES 등) | 응답 차이(손실)를 최소로 하는 θ 하나를 찾는다 | 단순하고 빠르다. 범위(불확실성)를 못 준다. 1차 값 용도 |
| **사후분포 추정 (BayesSim, NPDR)** | θ 의 분포를 구한다. NPDR 은 파라미터 상관(마찰과 접촉 강성이 같이 변하는 것)도 잡는다 | **DR 범위가 바로 나온다.** 요약 지표를 쓰면 한 번 돌린 시뮬레이션 수천 개로 된다 |
| 오프라인 데이터 최대우도 (DROPO) | 이미 모은 기록으로 무작위화 분포를 직접 맞춘다 | 새 실험이 필요 없다. 단, 상태 전체(몸통 위치·속도)가 필요하다. 이 로봇 기록은 일부 관측(관절, IMU)뿐이라 요약 지표 방식이 더 맞다 |
| 반복 적응 (SimOpt) | 정책 학습과 번갈아 분포를 갱신 | 실물 시험을 여러 번 해야 한다. 지금은 과하다 |

**권장: 점 추정으로 시작하고, 사후분포 추정(NPDR/BayesSim 방식)으로 범위를 낸다.** 출처는 `docs/research_raw/2026-11-04_friction_sysid_methods_sources.md`(요약만 읽음, 원문 미정독).

**식별 대상 θ**

| θ | 의미 | 사전 범위 (잠정) |
|---|---|---|
| μs | 발 마찰계수 (MuJoCo `geom_friction` 첫째 값) | (가)의 측정 구간, 없으면 0.3 ~ 2.0 |
| 접촉 강성 (solref 시간상수, solimp) | 접촉이 얼마나 말랑한가 → 발이 기어가는 속도를 정함 | 현재값의 0.5 ~ 4 배 |
| 접촉 마찰 비율 (impratio) | 옆으로 미는 힘의 단단함 | 1 ~ 100 (`docs/178` §4-5 에서 시험함) |
| hip_roll 관절 마찰 | 관절 안쪽 마찰 | 0 ~ 현재의 3 배 |

**관측 요약 지표** (실기와 Sim 모두 같은 식으로 계산)

1. 서기 구간 폭 변화율 [cm/s]와 목표 오차의 평균 (`tools/sim2real/walk/real_vs_sim_stand.py`).
2. (나) 시험의 미끄러짐 시작 순간의 Ft/Fn 과, 그때의 hip_roll 오차.
3. 목표 오차 계단 응답: 작은 계단(1°)과 큰 계단(5°)에서의 남는 오차 비율. 붙어 있으면 작은 계단에서 따라가지 못하고(정지 마찰), 큰 계단에서 갑자기 따라간다.
4. 걷기 폭·걷기 목표 오차(이미 Sim과 같음 → 식별의 검증 값으로 쓴다. 이 값이 바뀌는 θ 는 버린다).

**계산 순서**

1. **민감도 선별**: θ 를 하나씩 바꿔 위 지표가 움직이는지 본다. 움직이지 않는 θ 는 식별 대상에서 뺀다(이미 한 결과: 마찰만 바꾼 걷기 폭은 안 움직인다).
2. **점 추정**: 손실 = 정규화한 지표 차이의 합. 실기 한 번의 (나) 시험 + 기존 걷기 기록으로.
3. **사후분포**: 사전 범위에서 θ 를 뽑아 시뮬레이션 수천 번 → 요약 지표 → 신경망 추정기(SNPE-C 계열)로 사후분포. GPU 3090 에서 환경마다 θ 를 달리하면 병렬로 돈다(DR 이 이미 환경별 값을 지원한다).
4. **검증**: 사후분포에서 뽑은 θ 로 다시 재생해 **학습에 쓰지 않은 기록**(11-02 기록, 다른 날 걷기)의 지표를 맞히는지 본다. 못 맞히면 그 지표가 마찰 이외의 요인(바닥 변화, 발 하중 분포)을 가진 것이다.

# 4. 사후분포에서 DR 범위로

1. 사후분포의 95 % 구간 [lo, hi] 를 구한다.
2. **여유를 더한다**: 하한 lo × 0.8, 상한 hi × 1.2. (이유: 시뮬레이터가 모르는 요인(털 걸림, 마모, 오염)이 μ 로 흡수되어 있다. DROPO 도 "실물에만 있는 현상을 보충하려고 분포를 넓힌다"고 설명한다.)
3. **정책 한계로 잘라낸다**: 위 한계는 "현재 정책이 견디는 한계"(기존 발 1.5, 새 발 3.0)보다 낮게 둔다. 그보다 넓히려면 커리큘럼으로 점차 넓힌다.
4. **접촉 강성은 DR 에 넣는 것이 더 중요할 수 있다.** 서기 폭 차이는 마찰이 아니라 접촉 강성에서 온다고 보면, DR 에는 마찰 범위와 함께 접촉 강성 범위(식별한 구간)를 넣는다. 지금 DR 에는 접촉 강성이 없다. 49999 `env.yaml` 의 무작위화 이벤트 목록(`foot_friction`, `pd_gains`, `joint_friction` 등 24개)에 solref·solimp 를 바꾸는 항목이 없다. 바닥 접촉의 solref 는 학습 내내 `(0.03, 1.0)`, solimp 는 `(0.9, 0.95, 0.003, 0.5, 2.0)` 로 고정이다(같은 파일의 지형 설정). 시간상수 0.03 초는 단단한 값이 아니다.
5. 새 범위로 재학습한 뒤 **서기 폭 변화율과 목표 오차**를 Sim 에서 다시 재서 실기 값(변화율 ≈ 0)과 비교한다. 이 지표가 맞아야 식별이 성공이다.

# 5. 지금 할 수 있는 것과 필요한 것

**바로 할 수 있는 것 (Sim, 로봇 없이)**
- (나) 시험의 Sim 버전: 서 있는 Sim 로봇에서 hip_roll 목표를 천천히 올려 미끄러지기 시작하는 Ft/Fn 을 마찰 0.3~1.5, 접촉 강성 여러 값에서 잰다. 결과로 "Sim의 실제 정지 마찰이 설정값보다 얼마나 낮은가"와 "이 시험이 마찰·접촉 강성을 구별하는가(식별 가능성)"가 나온다. 이 결과가 나쁘면 시험 설계를 바꾼다.
- 위 지표를 계산하는 도구 정리(대부분 `tools/sim2real/walk/` 에 있음).

**실기가 필요한 것**
1. (가) 밑창·카펫 직접 측정(사람 손으로, 30 분).
2. (나) 로봇 응답 시험: 목표를 올리는 시험 스크립트와 **모터 전류 기록**(지금 기록에는 토크·전류가 없다, `docs/178` §5-4). 정책 없이 고정 목표를 보내는 스크립트가 필요하다.
3. 같은 시험을 매끈한 바닥과 카펫 두 곳에서 한다. 차이가 μ 의 바닥 의존이다.

**다음 결정이 필요한 것**
- 먼저 Sim 식별 가능성 시험(위 첫 항목)을 실행할지.
- 잠정 DR 상한 1.6 을 다음 학습에 넣을지(발 모델을 새 발로 바꾸는 재학습인지도 같이).

# 6. 한계

- 모든 문헌 정보는 검색 결과 요약만 읽었다. 방법 이름과 한 줄 요약만 믿고, 구현 세부는 원문 확인 후 쓴다.
- 마찰 하한 0.12 는 hip_roll 하나만 센 어림값이다.
- 잠정 상한 1.6 은 시뮬레이션 넘어짐 시험과 문헌 범위에서 나온 값이고, 재학습 시험은 하지 않았다.
- 카펫 털 걸림처럼 쿨롱 마찰로 표현되지 않는 현상은 μ 가 대신 흡수한다. 식별된 μ 는 "물리적 마찰계수"가 아니라 "Sim에서 이 응답을 내는 값"이다.
