# 159. 기사용 그림 — "원격 조종이 아니라 자율 주행" 레이아웃 시안

2026-10-07 · 김성우 교수님 피드백 (카카오톡) 에 대한 대응. 짝 문서: [[158_isaac_warehouse_lidar_demo]] (Isaac Sim 창고 데모).

## 1. 요구사항 정리

| 교수님 말씀 | 의미 | 그림에서 해야 할 일 |
|---|---|---|
| "기사로 실으려면 직관적이고 한눈에 들어와야" | 정지 이미지 1장, 설명 없이 읽혀야 함 | 요소를 5개 이하로. 글자는 크게, 센서 패널을 늘어놓지 않기 |
| "Remote control 이야기가 많이 나와서, 우리는 Autonomous Navigation 이 동작한다는 걸" | 조이스틱·원격 조종 느낌 제거. **스스로 판단**이 보여야 함 | "목적지 → 경로 → 주행" 흐름. 조이스틱·키보드 UI 금지 |
| "VLA 연구와 Autonomous navigation 하는 RViz 같은 영상" | 지도 위에 **계획 경로**가 있는 RViz 식 화면 + 언어로 목적지 지정 | 지도, 경로, 목적지 깃발, 자연어 명령, 로봇, 포인트클라우드 |
| "알고리즘 사진은 성민에게 받으면" | 알고리즘(내부 화면)은 다른 사람 자료. 우리는 시뮬레이션 주행 장면 | 이 시안은 시뮬레이션 + 계획 표시 |
| "우리는 알고리즘도 가지고 있다!" | 센서 나열이 아니라 인지 → 계획이 보이게 | 라이다 점은 "세상을 이해하는 증거"로 한 겹만, 경로가 주인공 |

정리: 주인공은 **초록 경로 + 목적지 깃발 + 언어 명령**이고, 로봇과 라이다 점(Isaac 실제 렌더)은 배경 증거다. 센서 패널(D435 등)은 작게 또는 아예 뺀다.

## 3. 무엇이 진짜이고 무엇이 시안용인가 (정직하게)

| 요소 | 상태 |
|---|---|
| 로봇 3D, 창고, 라이다 점(높이 색), D435 컬러·깊이 | **진짜** — Isaac Sim 렌더 (1920×1080 정지 화면, 글자 없이 저장) |
| 지도 | 같은 창고를 위에서 본 렌더를 점유 지도 모양(흰=빈 곳, 검정=선반, 파란 테두리=코스트맵)으로 바꾼 것. **SLAM 으로 만든 것이 아님** |
| 경로(초록), 목적지 깃발, 명령 문장, ETA·거리 | **시안용 그림.** 계획기가 아직 없다. 경로는 실제 카메라 자세로 바닥에 투영해서 장면과 맞게 그렸지만 계산된 경로가 아님 |
| "음성 명령" | 시안용. 언어 → 목적지 변환은 구현되어 있지 않음 |

그림 아래에 "LAYOUT MOCKUP" 표시를 넣었다. 기사용 최종본은 **진짜 계획 결과**로 다시 만들어야 한다 (아래 4).

## 4. 진짜로 만들려면 (제안, 아직 안 함)

1. **지도**: 이미 있는 라이다 점으로 2D/3D 점유 지도 만들기 (창고 걷기 영상의 누적 라이다 → 점유 격자). 기사용에는 SLAM 결과 화면이 더 설득력 있음.
2. **목적지 → 경로**: 지도 위에서 A*(전역) + 지역 회피. 명령어(자연어)는 **미리 정한 장소 이름 사전**(Dock A, Aisle 3) 으로 매핑해서 시작 (LLM 연결은 그다음).
3. **주행**: 경로를 따라 v11a 의 속도 명령(vx, 작은 yaw 보정)을 만든다. v11a 는 제자리 회전이 약해서 **완만한 곡선 경로만** 가능 — 시안의 경로도 그렇게 그렸다.
4. **캡처**: 같은 Isaac 장면에서 경로선·깃발을 Isaac 안에 직접 그려서 정지 이미지를 뽑는다 (지금은 2D 로 투영해 얹음).

## 7. 진짜 RViz 를 쓸 수 있나 — 확인 결과

| 곳 | 상태 |
|---|---|
| 177 (192.168.20.177) | ROS 2 Humble, `rviz2`, `nav_msgs`, `tf2`, `pcl`, `xacro`, `robot_state_publisher` **있음**. Nav2·SLAM Toolbox 없음, **가상 화면(Xvfb) 없음**, NVIDIA 드라이버 고장, sudo 암호 필요, 디스크 98 % |
| 3090 VM (10.8.0.14) | Isaac Sim 5.0 (ROS 2 다리 `isaacsim.ros2.bridge` 포함). 시스템 ROS 2 **없음**, Xvfb 없음, sudo 암호 필요, 디스크 여유 310 GB, 인터넷 됨 |

결론: **가능하다.** 가상 화면 위에서 RViz 를 띄워 화면을 캡처하면 헤드리스에서도 진짜 RViz 그림이 나온다. 3090 VM 에 설치하는 것을 권한다 (Isaac 과 같은 곳, 디스크 여유, 같은 IP).
설치 스크립트: `tools/isaac_demo/install_ros_rviz.sh` (VM 홈에 복사해 둠, `bash ~/install_ros_rviz.sh`, sudo 암호 필요, 약 10 분, 3 GB).
설치 후 할 일: ① 라이다 점(`PointCloud2`)·지도(`OccupancyGrid`)·경로(`Path`)·목적지(`PoseStamped`)·로봇 모델(URDF)을 ROS 로 내보내기 (Isaac 의 ROS 2 다리 또는 파이썬 발행기), ② RViz 설정 파일 만들고 가상 화면에서 캡처.
주의: RViz 쪽(시스템 파이썬 3.10)과 Isaac 쪽(venv 파이썬 3.11)은 **셸을 따로** 쓴다 (`~/ros_env_rviz.sh`, `~/pyg_demo/ros_env_isaac.sh`).

## 8. 진짜 RViz 캡처 + A안 최종 2종 (2026-10-07, 사용자 피드백 반영)

피드백: ① "하늘색이 시야를 가린다" ② 연구/전문적 + 자율주행 느낌 ③ 로봇 위치를 가깝게, 의미(Semantic) 요소 늘리기, 장애물 추가해 돌아가는 경로 ④ "음성명령" 대신 `CMD : …` 처럼 깔끔하게.

| 항목 | 한 일 |
|---|---|
| 하늘색 | RViz 첫 시험에서 **현재 라이다 스캔의 바닥 점**이 하늘색 판처럼 시야를 덮은 것. 바닥 점(높이 < 0.2 m)과 먼 점을 빼고, 흰 작은 점으로 바꿈 |
| 장애물 | Isaac 창고 통로에 **팔레트 + 상자 3개**를 추가(`--obstacles`). 통로에는 원래 작업대(테이블)도 있다. 로봇이 **실제로 돌아서 걸었다** (`--path-ref`: x −13.0 → −13.9 → −12.5 → −13.0, 쓰러짐 0). 계획 경로는 이 걸은 경로와 같다 |
| 로봇 위치 | 시작 `(-13, 3)`, 스냅샷은 y ≈ 10.9 (팔레트 6 m 앞). 목적지까지 17.8 m |
| 의미 요소 | 장애물(PALLET, TABLE: 빨간 상자), 선반(RACK A3-W/E: 주황 띠), 통로(AISLE 3 free), 목적지(GOAL Dock A: 깃발+원). **라벨은 시안용** |
| 문구 | 상단 막대에 `CMD : 3번 통로 끝 하역장(Dock A)으로 이동` (Consolas + 맑은 고딕, 58 px), 오른쪽 `NAV : PLANNING / GOAL : 17.8 m`. "음성 명령" 문구·마이크 아이콘·상태 칩·범례 삭제 |
| 상자 모서리 | 둥글기 3~5 px (거의 직각) |

**진짜 RViz**: 3090 VM(10.8.0.14)의 RViz2 를 가상 화면 2560×1440 에서 띄워 캡처한 것이다.
발행: 라이다 누적 점구름(6 cm 격자 19만 칸, Isaac 걷기에서 모은 실제 데이터), 현재 스캔, 로봇(URDF 메시를 색 입힌 마커로), 장애물 점유 격자, 경로, 목적지, 의미 라벨.
실제 데이터: 점구름·현재 스캔·로봇 자세·관절·장애물. 시안용: 계획 경로(걸은 경로를 그림), 목적지·라벨·상태 값. 계획기는 아직 없다.

시안 두 개 (둘 다 `docs/img/nav_layouts/`):
- `layout_A_rviz.png` — 연구/전문 느낌. RViz 전체 장면 + 로봇 근접 3D 삽입창 + 상단 `CMD :` 막대. 로봇 3D, 포인트클라우드 맵, 현재 라이다 점, 경로, 목적지, 장애물이 한 장에 들어간다.
- `layout_A_hero.png` — 사진 느낌. Isaac 렌더 위에 경로·깃발·`CMD :` 막대·작은 지도. 일반 독자용.

만든 법: `tools/isaac_demo/rviz/` (`capture_rviz.sh`, `publish_scene.py`, `scene.rviz`, `make_grid.py`, `compose_rviz_layout.py`), 설치는 `tools/isaac_demo/install_ros_rviz.sh`.
알려진 한계: RViz 글자(라벨) 간격이 넓게 렌더된다 (소프트웨어 OpenGL). 점유 격자 지도는 SLAM 이 아니라 창고 렌더에서 만든 것이고 이번 RViz 그림에서는 쓰지 않았다 (비용지도는 색이 너무 강해 뺐다).
