제어

진폭 ±° 주기초/왕복
목표 = 중심 + 진폭 × sin(2π t / 주기). 중심은 시작할 때의 목표 위치이고, 사인파가 도는 동안 위의 목표 슬라이더는 중심을 옮깁니다. 정지하면 그 순간 위치에 멈춥니다. 속도 목표는 0 으로 보냅니다(위치만).
토크를 켜는 순간 목표는 그때 측정한 위치로 맞춰지므로 튀지 않습니다.
