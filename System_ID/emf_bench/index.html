Control

Amplitude ±° Periods/cycle
Target = center + amplitude × sin(2π t / period). The center is the target position at the moment the sine starts; while the sine runs, the target slider above moves the center. Stopping holds the target where the sine was. The velocity target is sent as 0 (position only).
When torque is enabled the target is set to the position measured at that moment, so the shaft does not jump.

Logging

.csv
One row per control cycle with every loggable value (position, velocity, torque, target, gains, sine settings, VBUS, iqf, regen power, fault state, loop timing, counters). Empty cell = no value that cycle. Logging continues while the plots are paused. Files stay on the server and are listed under Saved logs.
